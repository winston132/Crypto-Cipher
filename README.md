# Cryptography & Network Security Analyzer

A Python toolkit implementing classical substitution and polyalphabetic ciphers, frequency-analysis cryptanalysis, and number-theoretic primitives supporting modern public-key cryptography (RSA and Diffie-Hellman).

## Included Modules (`ciphers.py`)
- **Caesar & Vigenère Ciphers**: Encryption and decryption utilities.
- **Frequency Analysis**: Letter distribution profiler for attacking monoalphabetic substitution ciphers.
- **Number Theory Primitives**: Extended Euclidean Algorithm (`extended_gcd`) and fast modular exponentiation (`mod_exp`).

## Run Demo
```bash
python3 ciphers.py
```
